# 🌦 Canada Weather Dashboard
The Canada Weather Dashboard is an interactive analytics platform designed for scientists, physicists, and engineers to explore historical weather trends across Canada.
The dashboard is built using Streamlit and integrates multiple APIs and visualization tools to analyze weather data.
### 🌐 Data Source
Weather data is retrieved from the Open-Meteo API, which provides location-based hourly weather observations across Canada.
### 🗺 Interactive Mapping
Interactive geographic visualization is implemented using Folium, enabling users to explore weather data by location.
### 📊 Key Visualizations
The dashboard includes multiple statistical and time-series visualizations to analyze Canadian weather patterns:
* 📦 Box Plots – Compare seasonal temperature distributions and identify mean and median trends
* 📉 CDF (Cumulative Distribution Function) – Analyze probability distribution of weather variables
* 🌬 Weibull Distribution – Evaluate wind behavior and variability
* 🌡 Temperature Time Series – Observe historical temperature trends over time
* 🧭 Wind Rose – Visualize wind direction and frequency patterns
* 
These visualizations help users quickly understand seasonal variability, distribution characteristics, and long-term weather trends across Canadian locations
